# SmartSpend – Budgeting and Spending Insight Web Application

## Overview
SmartSpend is a full-stack web application designed to help users track income, expenses, and budgeting habits through simple financial management tools and interactive dashboards.

## Planned Features
- User registration and login
- Add, edit, and delete transactions
- Categorize income and expenses
- Monthly spending summaries
- Budget progress tracking
- Spending charts
- Spending insights

## Tech Stack
- Frontend: React
- Backend: Node.js / Express
- Database: PostgreSQL
- Tools: GitHub, VS Code
