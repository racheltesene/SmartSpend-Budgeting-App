# Requirements

## Functional Requirements
- Users can create an account.
- Users can log in.
- Users can add income transactions.
- Users can add expense transactions.
- Users can edit transactions.
- Users can delete transactions.
- Users can categorize transactions.
- Users can view monthly totals.
- Users can view spending by category.
- Users can view budget progress.

## Non-Functional Requirements
- The app should be easy to use.
- The app should be responsive.
- User data should be secure.
- Dashboard data should load efficiently.

## Minimum Viable Product
- Login/register
- Add transactions
- View transaction list
- View monthly summary
- View at least one chart
