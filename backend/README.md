# Backend

This folder will contain the backend API for SmartSpend.

## Planned Features
- User registration
- User login
- Authentication
- Add transaction
- Edit transaction
- Delete transaction
- Get dashboard summary

## Planned API Routes
- POST /api/auth/register
- POST /api/auth/login
- GET /api/transactions
- POST /api/transactions
- PUT /api/transactions/:id
- DELETE /api/transactions/:id
- GET /api/dashboard/summary
